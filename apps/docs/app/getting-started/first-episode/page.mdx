# First Episode

A Tokovo episode is a pure definition plus a code-first timeline builder. Keep all frame-0 app state in `snapshot()` and `view()`, then use app track builders for timed story beats.

Import `episode` from `@tokovo/episodes/code-first-episode`. This is the canonical
creator surface: built-in apps are available as named methods and automatically inherit
the episode FPS and deterministic declaration order.

Create a file like `packages/episodes/src/stories/my-first-story.episode.ts`:

```ts
import { defineEpisode } from "@tokovo/episodes";
import { episode } from "@tokovo/episodes/code-first-episode";
import {
  cameraSubject,
  cinematicProgram,
  cinematicShot as shot,
} from "@tokovo/dsl";

const phone = cameraSubject.scope("phone", "app_whatsapp");

const cinematics = cinematicProgram(
  {
    fps: 30,
    duration: "10s",
    stage: {
      width: 1080,
      height: 1920,
      devices: [{ deviceId: "phone", x: 330, y: 510, width: 420, height: 889 }],
    },
  },
  (program) => {
    program.planFamily({
      plans: [{ id: "story-cut", default: true }],
      framings: {
        thread: {
          position: [0.5, 0.52],
          fill: 0.58,
          mode: "width",
        },
        reply: {
          position: [0.5, 0.64],
          fill: 0.34,
          mode: "width",
        },
      },
      outputs: [
        {
          id: "portrait-main",
          viewport: { x: 0, y: 0, width: 1080, height: 1920 },
          coveragePolicy: "require-shots",
          compositionProfileId: "hero-device",
          travel: {
            mode: "stabilized",
            subject: phone.body,
            maxDriftPx: [54, 72],
          },
          defaultRig: {
            id: "neutral",
            subject: phone.body,
            frame: { fill: 0.84, mode: "contain" },
          },
        },
      ],
      sequences: [
        {
          outputId: "portrait-main",
          end: "10s",
          shots: [
            shot("thread", "7.2s", phone.semantic("chat_thread"))
              .frame("thread")
              .guard(phone.body, { padding: 36 })
              .settle("420ms"),
            shot("reply", "2.8s", phone.semantic("last-message"))
              .frame("reply")
              .guard(phone.body, { padding: 36 })
              .settle("360ms"),
          ],
        },
      ],
    });
  },
);

export default defineEpisode({
  meta: {
    id: "my-first-story",
    title: "My First Story",
    description:
      "A short WhatsApp scene with explicit input and camera movement.",
    category: "production",
    catalogType: "story",
    visibility: "public",
    tags: ["whatsapp", "story"],
  },
  config: {
    format: "1080x1920",
    durationInFrames: 300,
    apps: ["app_whatsapp"],
  },
  build: () =>
    episode("my-first-story", {
      fps: 30,
      duration: "10s",
      title: "My First Story",
    })
      .device("phone", "iphone16", {
        app: "app_whatsapp",
        os: {
          time: new Date("2026-04-10T20:15:00Z"),
          battery: 82,
          network: "5G",
        },
      })
      .background({ type: "image", src: "/backgrounds/soft-gradient.png" })
      .cinematics(cinematics)
      .snapshot("app_whatsapp", "phone", {
        conversations: [
          {
            id: "dm_alex",
            name: "Alex",
            unreadCount: 1,
            messages: [
              {
                id: "seed_1",
                from: "Alex",
                text: "Can you make the intro feel like a real phone recording?",
                at: new Date("2026-04-10T20:14:00Z").getTime(),
              },
            ],
          },
        ],
      })
      .view("app_whatsapp", "phone", {
        screen: "chat",
        conversationId: "dm_alex",
      })
      .whatsapp("phone", "dm_alex", (wa) => {
        wa.at("5s").send(
          "Yes. Typing, camera, and phone chrome are all scripted.",
          {
            input: { duration: "3.6s", style: "fast" },
          },
        );
        wa.at("7.2s").receive("Alex", "Perfect. Render it.");
      }),
});
```

Register it in the relevant catalog, then run:

```bash
pnpm validate
EPISODE_ID=my-first-story pnpm --filter video-runner render:fast
```

## Authoring Rules

- Use `snapshot()` and `view()` for initial state.
- Use app track builders for timed interactions.
- For normal WhatsApp sends, use structured `input` intent on `send()` so one
  semantic action authors the draft, submit, message, and exit.
- Use `.input(deviceId, fieldId, ...)` for advanced cursor, IME, suggestion,
  paste, voice, or cross-field choreography. Both paths compile to the same
  canonical input program.
- Use `.notificationTrack(deviceId, ...)` for delivery, center, dismiss, tap,
  action, and quick-reply choreography. Apps provide content/action adapters;
  the device notification capability owns policy and presentation.
- Author OS `locale`, `appearance`, `hourCycle`, and wallpaper on the device.
  OS appearance is separate from app appearance.
- Use `.whatsapp()`, `.imessage()`, `.instagram()`, `.x()`, `.linkedin()`,
  `.snapchat()`, `.teams()`, or `.typewriter()` for built-in apps. Do not construct
  their track builders manually.
- Keep assets under `packages/assets/public`.
- Prefer stable semantic subjects such as `chat_thread`, `last_message`, `tweet_card`, or app-specific subjects.
- For narrative episodes, group beats with `.scene()`, use `scene.wait()` for relative
  pacing, and use returned message/post handles for camera targets.
- Use `.cinematics(...)` for replaceable named CameraPlans. Camera direction never enters story
  replay state.
- Run `pnpm validate` after registering an episode.
