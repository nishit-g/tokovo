# Installation

Get the Tokovo monorepo running locally.

## Prerequisites

- mise
- Git

## Clone

```bash
git clone <YOUR_REPO_URL>
cd tokovo
```

## Install Dependencies

```bash
mise install
mise exec -- node --version
mise exec -- pnpm --version
mise exec -- pnpm install
```

`.mise.toml` is the single source of truth for the exact Node.js and pnpm versions. Activate mise in
your interactive shell to use plain `pnpm ...` commands; use `mise exec -- pnpm ...` in CI and other
non-interactive shells.

## Main Apps

- `apps/web`: marketing site
- `apps/video-runner`: Remotion render app
- `apps/docs`: documentation site

## Main Package Groups

- compiler and authoring: `ir`, `core`, `dsl`, `compiler`, `episodes`, `camera`
- device and OS: `devices`, `device-keyboard`, `device-notifications`, `overlay`
- app plugins: `apps-whatsapp`, `apps-imessage`, `apps-x`, `apps-linkedin`, `apps-snapchat`, `apps-teams`, `apps-typewriter`
- rendering and media: `react`, `renderer`, `background`, `voice`

## Useful Commands

```bash
pnpm -s typecheck:solution
pnpm validate
pnpm --filter @tokovo/episodes test
pnpm build:video
pnpm --filter docs build
```

## Local Entry Points

```bash
pnpm --filter video-runner dev
pnpm --filter docs dev
pnpm --filter web dev
```
