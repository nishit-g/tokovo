# @tokovo/apps-x

The hard-cut X plugin package for deterministic Tokovo episodes.

## Responsibilities

- normalized schema V2 state with strict snapshot, view, event, and reference validation
- iOS/Android presentation with native light, dim, and lights-out experiences
- English, Arabic RTL, and Hindi localization
- timeline, post detail, compose, notifications, profile, DM inbox, and DM thread surfaces
- bounded feed/thread projection for large authored datasets
- stable semantic and exact-entity camera subjects
- typed authoring, notification adapter, semantic audio, and complete asset collection

The package does not migrate or silently repair V1 data. Repository episodes author version 2 explicitly; an installed app without seeded content receives a canonical empty V2 state.

## Showcase proofs

- `x-cinematic-flagship`: the public 42-second cinematic episode
- `x-interaction-matrix-vnext`: platform and interaction lifecycle coverage
- `x-native-theme-matrix-vnext`: light, dim, lights-out, English, Arabic RTL, and Hindi

## Key Exports

- root package for authoring DSL and public X types
- `@tokovo/apps-x/plugin` for runtime registration
- `@tokovo/apps-x/contract` for bootstrap and event contracts
- `@tokovo/apps-x/runtime` for reducer state and selectors
- `@tokovo/apps-x/dsl` for track builders and authoring helpers
- `@tokovo/apps-x/lowering` for event lowering
- `@tokovo/apps-x/ui` for React surfaces
