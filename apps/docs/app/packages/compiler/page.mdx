# @tokovo/compiler

The compilation layer between authored episode input and runtime replay.

## Responsibilities

- lower authored events and tracks into runtime data
- validate and migrate plugin-owned snapshots and initial views
- hydrate initial world state through plugin bootstrap contracts
- host compile-time plugins such as camera and typing-indicator helpers
- prepare explicit input sessions into a deterministic input program
- prepare notification intents, policy, interactions, and typed action effects into an
  immutable notification program

`@tokovo/compiler` does not own app-domain bootstrap semantics. It orchestrates plugin-owned
snapshot/view schemas; it does not synthesize chats, feeds, or threads on behalf of apps.

## Key Exports

- preparation: `prepareTrackEpisode`
- lowering helpers: `lowerTrackEvent`, `lowerTrackEvents`, `lowerEpisode`
- plugin contracts: `CompilerPlugin`, `CompilerContext`
- built-in plugins:
  - `CameraDirectorPlugin`
  - `AudioDirectorPlugin`
  - `OSDirectorPlugin`
  - `TypingIndicatorPlugin`

## Important Boundary

Compiler correctness depends on explicit plugin registration and globally unique runtime event kinds.
If a plugin lowerer or bootstrap contract is missing, the compiler should fail loudly instead of
guessing.
