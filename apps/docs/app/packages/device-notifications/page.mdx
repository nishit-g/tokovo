# @tokovo/device-notifications

Deterministic notification compilation, replay, projection, audio, and presentation.

## Responsibilities

- prepare immutable notification programs from semantic app intents
- evaluate delivery, dismissal, expiry, grouping, and center state at any frame
- enforce privacy, preview, foreground, DND, interruption, and delivery conditions
- route typed actions and quick replies into normal navigation and app events
- project localized iOS and Android light/dark surfaces
- render banners, lockscreen cards, and notification center through one painter

## Key Exports

- `prepareNotificationProgram`
- `evaluateNotificationProgram`
- `projectNotifications`
- `projectNotificationAudioCues`
- `getNotificationTheme`
- `NotificationSurface`

Apps own notification content adapters and action targets. This package owns device
policy and visual projection. There is no parallel notification store in core and no
second notification renderer.
