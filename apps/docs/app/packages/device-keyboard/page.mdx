# @tokovo/device-keyboard

Deterministic, multilingual text-input capability and keyboard projection.

## Responsibilities

- field-scoped input-session contracts
- grapheme-safe editing, selection, composition, and submission
- locale, script, direction, platform, and appearance resolution
- deterministic runtime evaluation and keyboard projection
- one canonical keyboard renderer

## Key Exports

- contracts: `InputSessionDefinition`, `InputOperation`, `InputProjection`
- preparation: `prepareInputProgram`
- replay: `evaluateInputProgram`
- projection: `projectInputSession`, `findInputSessionForProjection`
- UI: `InputKeyboard`, `resolveInputKeyboardRows`
- theme and presentation resolvers

WhatsApp's structured `send(..., { input })` is the common semantic path. The
explicit `.input(...)` builder remains available for advanced editing and IME
choreography; both lower to identical prepared input sessions.
